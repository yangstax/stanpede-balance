# STANPEDE live balance

[Live config](https://yangstax.github.io/stanpede-balance/v1/balance.json) · [Edit on GitHub](https://github.com/yangstax/stanpede-balance/edit/main/v1/balance.json)

`v1/balance.json` is the live source for pacing, fan stats, ability values/names/descriptions, XP, Hype, pickups and Training. Pushing a valid change to main publishes it through GitHub Pages. The game applies downloaded settings between matches and keeps a valid offline copy.

## Change it from ChatGPT on your phone

Use a **Codex Cloud** environment connected to this repository. Once the environment is published, select it in the mobile ChatGPT app's Codex section and ask for a change, for example:

> Keep fan/single/rival levels at 12/16/20, but increase late swarm sizes by 10%. Validate, commit and publish to main, then verify the live config.

The repo's `AGENTS.md` supplies the publishing and validation instructions. Your computer can be asleep. Creating the environment is a one-time web/desktop step: Settings → Codex Cloud → Environments → Create environment, choose `yangstax/stanpede-balance`, let setup install `requirements.txt` and run the checks, then Publish.

[Official Cloud setup](https://learn.chatgpt.com/docs/environments/cloud-environments)

## Validate locally or in Cloud

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest test_validation.py
python3 validate.py
```

The schema is generated by the game's actual validator. Publication also checks milestone order, matching swarm arrays and complete supported fan/ability IDs. The served revision is the source commit, making changes and rollbacks traceable.

To roll back, revert the relevant config commit and push main. A current match keeps its existing settings; the next downloaded snapshot applies between matches.
